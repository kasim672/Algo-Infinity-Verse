What this editor supports

  • Variables — local and global, multiple assignment
  • All arithmetic, comparison, and logical operators, plus .. concatenation
  • Control flow — if/elseif/else, while, repeat/until, numeric and generic for
  • Functions — named, local, anonymous, closures, multiple return values
  • Tables — constructors, indexing, # length, nesting
  • Method-call sugar obj:method() and metatables with __index (enough for classic OOP-style Lua)
  • Built-ins: print, type, tostring, tonumber, pairs, ipairs, next, setmetatable, getmetatable, pcall, error, assert
  • string.* (format, sub, upper, lower, len, rep, byte, char, find, reverse), table.* (insert, remove, concat), math.*
  • Comments — -- line and --[[ ]] block

Not supported: varargs (...), goto/labels, coroutines, full Lua pattern matching (string.find here is plain-text only), bitwise operators, multi-level long brackets, and metamethods other than __index. This runs a small interpreter built for this editor, not a full Lua engine — see the Lua manual for the complete language.
