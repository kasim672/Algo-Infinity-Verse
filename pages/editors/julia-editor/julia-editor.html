What this editor supports

  • Variables, arithmetic (+ - * / % ^), and comparisons
  • String interpolation: "value is $(x)"
  • Control flow: if / elseif / else
  • for loops over arrays and ranges (1:10, 1:2:10)
  • while loops, plus break and continue
  • Functions, including recursion, closures, and short form (f(x) = x^2)
  • Arrays: literals, 1-based indexing, push!, pop!
  • Built-ins: println, print, length, sum, mean, maximum, minimum, abs, sqrt, round, floor, ceil, collect, reverse, sort, zeros, ones, string, typeof, rand
  • plot(), scatter(), bar(), histogram() rendered on canvas from your actual data

Not supported: Pkg.add / package installs, anonymous/lambda functions, multiple dispatch, macros, real Plots.jl rendering, or most of the Julia standard library. This runs a small interpreter built for this editor, not a full Julia engine — Julia has no in-browser runtime, and the backend's live execution path doesn't support Julia.
