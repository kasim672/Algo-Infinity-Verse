🌳 Why Euler Tour + Sparse Table?

🛤️

Euler Tour Flattening

We traverse the tree using DFS and record every node we visit, including when we backtrack. This creates an array representation of the tree where any path between two nodes is captured.

⬇️

Lowest Depth

Between the first occurrences of any two nodes u and v in the Euler Tour, the node with the minimum depth is exactly their Lowest Common Ancestor (LCA). The tree problem is now an array RMQ problem.

🧮

Sparse Table RMQ

A Sparse Table precomputes the minimum depth for all range lengths that are powers of 2. It takes O(n log n) time to build, but allows answering any Range Minimum Query (RMQ) in true O(1) time.

⚡

O(1) Queries

To find the minimum in any range [L, R], we find the largest power of 2 (let's say 2^j) that fits in the range. We then compare the precomputed minimums of two overlapping blocks: [L, L+2^j-1] and [R-2^j+1, R].
