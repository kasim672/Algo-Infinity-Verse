Deterministic Skip List

Randomization Isn't the Only Way to $O(\log N)$

Standard Skip Lists rely on coin flips, providing expected $O(\log N)$ searches. But what if you get terribly unlucky? A Deterministic (1-2-3) Skip List eliminates randomness entirely. By enforcing a strict structural invariant (always 1 to 3 nodes between taller nodes), it guarantees strict $O(\log N)$ worst-case bounds, much like a B-Tree!

✨ How It Works

🎲

Randomized Promotion

The standard Skip List flips a coin to decide a node's height. If it lands Tails forever, your skip list devolves into a flat linked list, completely ruining your $O(\log N)$ search time. It's rare, but theoretically possible in adversarial scenarios.

📏

The 1-2-3 Invariant

Deterministic skip lists throw out the dice. Instead, they enforce a strict rule: between any two nodes of height $H$, there must be exactly 1, 2, or 3 nodes of height $H-1$. This strictly bounds the tree height mathematically.

⚖️

Cascading Rebalances

When you insert a node, it starts at height 1. If this creates a gap of 4 height-1 nodes, the algorithm detects it and forces the 2nd node to promote to height 2. If this creates a gap of 4 height-2 nodes, it cascades upwards! This is isomorphic to B-Tree splitting.
