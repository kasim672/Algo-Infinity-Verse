Ternary Search

Finding Peaks Without Derivatives

While Binary Search halves a search space to find exact values, Ternary Search cuts the search space into thirds to find the MAXIMUM (or minimum) of a unimodal function. By evaluating two interior points and comparing them, it can confidently discard exactly 1/3 of the space per iteration—no calculus required!

✨ The Rules of Ternary Search

⛰️

The Unimodality Precondition

Ternary search ONLY works if the function strictly increases to a single peak, and then strictly decreases (or vice versa for minimums). If there are multiple peaks, flat plateaus, or noisy ripples, the "discard 1/3" logic will accidentally throw away the true maximum. Try the "Double Peak Trap" demo!

✂️

Shrinking by 2/3

Unlike Binary Search which requires 1 evaluation to discard 1/2 the space, Ternary Search requires 2 evaluations to discard 1/3 of the space. While it converges slightly slower mathematically ($O(\log_{1.5} N)$), it solves a strictly harder problem without needing gradients or derivatives.

🏭

Real Applications

It's used extensively in optimization: finding the optimal split of resources between two factories (where total cost forms a U-shape), finding the angle that maximizes projectile distance, or tuning hyperparameters in machine learning where the loss function is convex.
