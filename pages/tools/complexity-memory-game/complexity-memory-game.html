Guide

How to Play

1
Select your difficulty

Easy: 4×4 grid with basic complexities. Medium: 4×4 expanded. Hard: 6×4 grid with advanced complexities.

2
Flip two cards

Click a card to reveal it — you'll see either an algorithm name or a complexity label.

3
Find the match

If the algorithm matches its complexity, the pair stays revealed. If not, they flip back.

4
Earn bonuses

Match quickly (<500ms) for a lightning bonus — consecutive matches build your streak!

5
Beat your best

Your best score per difficulty is saved locally. Replay to top it!
